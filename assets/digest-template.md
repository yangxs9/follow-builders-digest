# Digest 模板

## 报告模板

```markdown
# Follow Builders Weekly Digest｜{{日期范围}}

## X：Builders 在讨论什么

{{按下方条目模板写精选内容}}

## 博客：值得细读的文章

{{按下方条目模板写精选内容}}

## 播客：值得展开听的讨论

{{按下方条目模板写精选内容}}
```

## 条目模板

```markdown
### {{具体、易懂的标题；播客可加节目名}}

**{{一句话概括核心观点，明确观点属于谁。}}**

{{一到两段中文：交代背景、具体例子和关键取舍。}}

> {{英文原文摘录：可以是点明观点的短句，也可以是保留必要上下文的一段连续原文。}}

{{如有必要，继续补充观点的背景、具体例子或关键取舍；}}

{{重要内容可继续穿插英文原文，让引用与中文内容自然衔接。}}

[{{作者或节目名称}}]({{原始链接}})
```
